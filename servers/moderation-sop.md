# Server moderation SOP

Standard operating procedures for RP server staff. Adapt channel names and tools to your stack.

## Roles

| Role | Responsibility |
|------|----------------|
| Moderator | Chat patrol, ticket first response |
| Admin | Bans, economy fixes, event hosting |
| Lead | Policy updates, escalations |

## Response times

- **P0** (doxxing, threats): immediate, any online staff
- **P1** (harassment, cheating accusations): within 15 minutes during peak
- **P2** (rule questions, LFG): within 1 hour

## Strike system

1. Verbal warning (logged in `#mod-log`)
2. 24h mute
3. 7-day ban
4. Permanent ban (lead approval)

## Ticket workflow

1. User opens ticket with template (rule break / appeal / report)
2. Mod acknowledges within SLA
3. Collect evidence (screenshots, clip links — official captures only)
4. Resolve with documented outcome
5. Archive ticket after 7 days

## Voice / stream sniping

- No sharing live locations of players in competitive contexts
- Event channels are moderated; raids from other servers = instant ban

## IP safety

- No leaked footage or datamined content in tickets or public channels
- Link official sources only in `#news`

## Weekly mod sync

- Review strike log
- Update pinned rules if repeat offenses cluster
- Escalate economy exploits to dev track (`scripts/custom-jobs` audit logs)

## KPIs

- Median ticket response time
- Reopened ticket rate
- Active mod hours vs peak concurrent players
